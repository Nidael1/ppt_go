## Fuente retro

Se recomienda VT323 (Google Fonts) para la estética de 8 bits.
Alternativa: Press Start 2P (más auténtica, menos legible en tamaños pequeños).

## Paleta de colores sugerida

- Fondo: #0d0d0d (negro casi puro)
- Texto principal: #33ff33 (verde fósforo)
- Acento: #ff9900 (naranja arcade)
- Error/derrota: #ff3333
- Victoria: #33ff33
